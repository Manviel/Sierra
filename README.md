# Sierra 🚀

Sierra is a modern, high-performance web application built with **Nuxt 3**. Originally a learning project for full-stack development, it has been migrated to the latest industry standards to provide a seamless developer experience and a snappy user interface.

## ✨ Features

- **Nuxt 3 framework**: Leveraging the latest Vue 3 features and Nitro engine.
- **Pinia State Management**: Fast and type-safe state management.
- **Bootstrap 5 & FontAwesome 6**: Modern UI components and rich iconography.
- **Dynamic Routing**: Simplified dynamic pages and layouts with standard [id].vue naming.
- **Admin Panel**: Secure administrative routes with custom middleware.
- **Isomorphic Fetching**: Robust data fetching patterns with `useAsyncData`.

## 🛠️ Tech Stack

- **Framework**: [Nuxt 3](https://nuxt.com/)
- **State**: [Pinia](https://pinia.vuejs.org/)
- **UI**: [Bootstrap 5](https://getbootstrap.com/)
- **Icons**: [FontAwesome 6](https://fontawesome.com/)
- **Language**: JavaScript / ESM

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Sierra
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```

## 📂 Project Structure

- `app.vue`: The main entry point of the application.
- `pages/`: Application routes and views.
- `layouts/`: Shared UI structures.
- `components/`: Reusable Vue components.
- `stores/`: Pinia store definitions.
- `plugins/`: Nuxt plugins (e.g., FontAwesome configuration).
- `middleware/`: Navigation guards and route logic.
- `public/`: Static assets.
